# Latest AI-driven software technology (relay web research, 2026-10-19)

Gathered by the relay (ASE Steward) because the architects cannot browse. Paraphrased, one line each, with the source.
Confidence: HIGH = primary source or several agreeing sources; LOW = a single secondary roundup or a vendor blog, unverified.
Cite findings by ID (for example F07) in every idea.

## Coding agents and models
- F01 (LOW) Google released Gemini 4 Argon on 2026-10-14, aimed at long-horizon work such as code migration and cybersecurity. Source: manaknightdigital.com AI news week of 2026-10-16; aiagentstore.ai weekly news.
- F02 (MEDIUM) Google Antigravity 2.0 (stable 2.23.1) shipped 2026-10-13 as an agent-first development environment. Source: Wikipedia "Google Antigravity".
- F03 (LOW) IBM launched a self-hosted version of its coding agent so enterprises run it inside their own secure environments. Source: news roundups, early October 2026.
- F04 (LOW) AWS added a skill to its Agent Toolkit letting coding agents drive model training and tuning through natural-language workflows (2026-10-13). Source: news roundups.
- F05 (MEDIUM) Claude Code added automatic fallback to a configured backup model when the primary is unavailable (early October 2026). Source: release notes summarized in news roundups.
- F06 (LOW) A roundup reports typical AI coding sessions grew from about 4 to about 23 minutes. Source: Medium roundup, 2026-10-04. Treat as anecdotal.
- F07 (LOW) Public coding-agent leaderboards disagree with each other; scores and per-task costs vary widely by source. Source: morphllm.com leaderboard, benchmark aggregators.

## Verification and multi-agent research
- F08 (MEDIUM) Verification-aware planning: the planner writes a verification function per subtask, and the coordinator uses it to proceed, retry or replan. Source: "Verification-Aware Planning for Multi-Agent Systems" (VeriMAP), 2026.
- F09 (MEDIUM) Meta-Agent builds multi-agent systems from task descriptions and verifies them at construction time, not only after they run. Source: arXiv 2605.25233.
- F10 (MEDIUM) Paper title: "Self-Authored Verification Is Unreliable in Heuristic Self-Improving Agents" (only its references were readable). Source: arXiv 2607.24300.
- F11 (MEDIUM) Independent patch verification for coding agents: reconstruct the intent of a patch, then verify it separately from the agent that wrote it. Source: arXiv 2608.08950 (only the bibliography was readable).
- F12 (MEDIUM) A survey of the agentic software lifecycle reports a coordination penalty for multi-agent teams, low success on very long tasks, high token use, weak self-verification and reward hacking; it calls for durable state, structured coordination, adversarial verification, bounded permissions, progress accounting and recovery from partial failure. Source: arXiv 2609.04681.
- F13 (MEDIUM) "Software engineering in the agent era: from trustworthy change to human-agent software organizations" frames teams of people and agents as organizations. Source: arXiv 2609.04630 (title only read).

## Governance and human oversight
- F14 (HIGH) The EU AI Act's obligations for high-risk systems include human oversight (Article 14) and auditability, with enforcement from August 2026. Source: atlan.com checklist and other guides.
- F15 (MEDIUM) A common guardrail frame: permission, approval, audit trail and kill switch. Source: querypie.com 2026 whitepaper.
- F16 (MEDIUM) Tool-call gating: when a call's risk passes a threshold, execution halts in a pending-approval state until a person confirms. Source: arXiv paper on bounded autonomy and typed action contracts (2604.14723); academic, not production-validated.
- F17 (LOW) Governance tooling for agents (inventory, runtime tool authorization, approval points, observability) is the least supplied part of most vendors' offerings; open-source options include LlamaFirewall, LlamaGuard and approval-receipt logging. Source: domo.com review, github awesome-ai-agent-governance.

## Accessibility and UI generation
- F18 (MEDIUM) Rules-based accessibility scanners (axe-core, Pa11y) remain the core; AI is mostly layered on top, for example computer vision that finds interactive elements the markup does not describe. Source: webyes.com, browserstack.com guides.
- F19 (LOW) Some accessibility tools now drive a coding agent to fix issues, test the fix and ask a developer to approve. Source: vendor blog summaries.
- F20 (LOW) Automated accessibility testing is said to catch roughly 30-40% of WCAG issues; screen-reader and keyboard testing still need people. Source: a vendor's own guide; treat as an estimate.
- F21 (MEDIUM) "Design Theater": a 2026 study of the gap between the design reasoning generative UI tools show users and what they actually implement. Source: arXiv 2607.22928.
